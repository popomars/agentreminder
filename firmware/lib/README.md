# Board driver sources

The small ArduinoGFX and SensorLib subsets here are copied from Waveshare's
[official ESP32-S3-Touch-AMOLED-2.16 examples](https://github.com/waveshareteam/ESP32-S3-Touch-AMOLED-2.16/tree/main/examples/arduino/libraries).
ArduinoGFX is version 1.6.4. SensorLib contains the CST92xx driver and its platform
helpers only; unrelated sensor drivers and examples are omitted. Source license
headers are preserved. The pin map and axis transforms follow `05_LVGL_Widgets`.
